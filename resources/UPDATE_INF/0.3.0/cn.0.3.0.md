# World Editor v0.3.0

## 新增功能

### 快捷键系统
- `F1` 或 `Ctrl+/`：显示快捷键帮助面板
- `Ctrl+S`：保存当前文件
- `Ctrl+N`：新建文件/项目
- `Ctrl+O`：打开项目
- `Ctrl+W`：关闭当前标签
- `Ctrl+Tab` / `Ctrl+Shift+Tab`：切换标签
- `Ctrl+1~9`：跳转到指定标签

### 快捷键自定义设置
- 在设置页面新增"快捷键"分类
- 点击输入框后按下按键组合即可修改
- 支持冲突检测，避免重复绑定
- 每个快捷键可单独恢复默认
- 设置持久化保存，重启后生效
- 快捷键帮助面板自动同步显示自定义快捷键

### 标签右键菜单
- 固定/取消固定标签（固定标签会移至最前并显示标识）
- 关闭标签
- 关闭其他标签
- 关闭右侧标签
- 重命名标签

### 实时编辑统计
- 字数统计
- 字符数统计
- 段落数统计
- 预计阅读时间（基于每分钟 200 字）

### 文件拖放导入
- 支持从系统拖入文件到应用
- 支持格式：.txt, .md, .doc, .docx, .rtf, .log, .csv, .json, .xml, .html, .css, .js
- 拖入时显示导入预览界面
- 自动处理文件覆盖提示

## 界面优化

- 关闭按钮红色修正为 Windows 标准红 `#e81123`
- 窗口缩放底色修复，与界面背景统一
- 进度条对比度增强，轨道和填充色区分明显
- 快捷键帮助面板美化设计
- 标签右键菜单现代化样式
- 状态栏增强，显示实时编辑统计

## Bug 修复

- 修复窗口可无限缩小的问题（添加最小尺寸限制 800x500）
- 修复窗口缩放时底部背景突兀的问题
- 修复主题切换时窗口底色不跟随更新的问题
- 修复 Quill 工具栏显示/隐藏的兼容性问题
- 修复更新日志 Markdown 渲染的一些细节
