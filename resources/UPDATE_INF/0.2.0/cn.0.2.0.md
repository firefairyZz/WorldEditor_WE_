# World Editor v0.2.0

## 新增功能

- **标签系统**：为文件添加彩色标签，支持文字和表情
- **图片缩略图**：可为文件设置缩略图，图片存储在项目目录内
- **内嵌功能**：目录生成、字数统计、Markdown 导出
- **搜索功能**：支持文件名、标签、内容搜索
  - 通配符支持（* 和 ?）
  - 模糊查找
  - 多类型筛选
  - 结果排序
- **文件树优化**：可调宽侧边栏、展开/收起三角形改进

## 界面优化

- 编辑界面美化
- 搜索栏可折叠
- 筛选按钮改为开关样式
- 响应式布局改进

## Bug 修复

- 修复元数据加载竞态条件
- 修复 TOC 位置计算错误
- 修复 Markdown 导出链接格式
- 修复 CSS 兼容性问题
