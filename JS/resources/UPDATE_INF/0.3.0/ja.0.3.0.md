# World Editor v0.3.0

## 新機能

### ショートカットシステム
- `F1` または `Ctrl+/`：ショートカットヘルプパネルを表示
- `Ctrl+S`：現在のファイルを保存
- `Ctrl+N`：新規ファイル/プロジェクト
- `Ctrl+O`：プロジェクトを開く
- `Ctrl+W`：現在のタブを閉じる
- `Ctrl+Tab` / `Ctrl+Shift+Tab`：タブを切り替え
- `Ctrl+1~9`：指定したタブにジャンプ

### ショートカットカスタマイズ
- 設定ページに「ショートカット」カテゴリを新設
- 入力ボックスをクリックしてキー組み合わせを押すだけで変更可能
- 重複バインディングを避けるための競合検出
- 各ショートカットは個別にデフォルトに戻せます
- 設定は永続化され、再起動後に有効
- ショートカットヘルプパネルがカスタムショートカットを自動同期

### タブ右クリックメニュー
- タブをピン留め/解除（ピン留めタブは先頭に移動し識別表示）
- タブを閉じる
- 他のタブを閉じる
- 右側のタブを閉じる
- タブ名を変更

### リアルタイム編集統計
- 単語数カウント
- 文字数カウント
- 段落数カウント
- 推定読書時間（1 分間 200 単語ベース）

### ファイルドラッグ&ドロップ読み込み
- システムからアプリへのファイルドラッグをサポート
- 対応形式：.txt, .md, .doc, .docx, .rtf, .log, .csv, .json, .xml, .html, .css, .js
- ドラッグ時に読み込みプレビューを表示
- ファイル上書きの自動確認プロンプト

## インターフェース改善

- 閉じるボタンの赤色を Windows 標準の赤 `#e81123` に修正
- ウィンドウリサイズ時の背景色を修正、インターフェース背景と統一
- プログレスバーのコントラストを強化、トラックと塗りつぶし色を明確に区分
- ショートカットヘルプパネルのデザインを美化
- タブ右クリックメニューをモダンなスタイルに
- ステータスバーを強化、リアルタイム編集統計を表示

## バグ修正

- ウィンドウが無限に縮小できる問題を修正（最小サイズ 800x500 を追加）
- ウィンドウリサイズ時の下部背景の不自然さを修正
- テーマ切り替え時にウィンドウ背景色が更新されない問題を修正
- Quill ツールバーの表示/非表示の互換性問題を修正
- 更新履歴の Markdown レンダリングの詳細を修正
