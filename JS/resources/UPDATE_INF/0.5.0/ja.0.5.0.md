# World Editor v0.5.0

## 新機能と改善
- **マルチフォーマット書き出し**：「Markdown 書き出し」ボタンをドロップダウンメニューに昇格し、**Markdown / HTML / PDF / ZIP** の4形式に対応。PDF は非表示ウィンドウの `printToPDF` で生成（A4・余白なし・背景色保持）、ZIP はプロジェクト全体をパッケージ化。
- **背景マテリアルシステムの強化**：マテリアル種別に**タブ式 (Tabbed)** を追加。さらに**コンテンツ / オーバーレイ / タイトルバー**の3層透明度スライダー（既定 78% / 30% / 100%）を追加し、設定ページでリアルタイムプレビュー。マテリアルが「なし」の時はスライダーを自動で無効化。
- **新しい言語パック**：**日本語**と**ロシア語**の完全な翻訳を追加し、言語ドロップダウンにも対応する選択肢を追加。
- **タグのカスタムカラー**：プリセットパレットの横にカラーピッカーを追加し、任意の色を指定可能。双方をリアルタイムに同期。
- **保存のデバウンス**：保存中に再度保存要求が来た場合はキューイングして自動的に追保存。保存中は「保存中...」の通知を常時表示し、完了後に「保存済み」へ切替。
- **起動の最適化**：メインウィンドウを `ready-to-show` 後に表示するよう変更し、起動時の白いフラッシュを解消。
- **ピンアイコン**：`pin.svg` リソースに切替。`rotate(45deg)` でアクティブ状態を区別。
- **レイアウトとスタイル**：ページを title-bar / tab-bar / #main の3段構成に再構築。`html`/`body` は常に透明とし、不透明色は各子ブロックが担うように変更。タグ選択ダイアログにすりガラスオーバーレイとスライドアップアニメーションを追加。
- **国際化の更新**：タグ・アカウント・外観（マテリアル＋配色）各セクションの多言語リフレッシュを完了。

## バグ修正
- リッチテキスト読み込み時の改行・フォーマット解析の乱れを修正（HTML は `dangerouslyPasteHTML`、プレーンテキストは `setText` を使用）。
- Quill ヘッダードロップダウンの既定値による本文フォーマット異常を修正（既定値を `""` から `"false"` に変更）。
- 配色プリセット切替後に古い半透明色が新テーマを汚染する問題を修正（切替時にテーマ色キャッシュをクリアしマテリアルを再適用）。
- ウィンドウの不透明背景色がマテリアル効果を上書きする問題を修正（ウィンドウは常に透明、角丸は CSS `clip-path` で処理）。
- ファイル名表示を正規化：ジャンプダイアログ、タイトル、書き出しファイル名で拡張子とパスを一貫して削除。
