# World Editor v0.4.0

## 新機能

### マルチテーマシステム
- 13 種類のプリセットテーマを内蔵
  - ライト：WE Exclusive、デフォルトライト、GitHub Light、Solarized Light、Nord Light
  - ダーク：デフォルトダーク、Dracula、Monokai、Solarized Dark、Nord、GitHub Dark、One Dark
- カスタムテーマ：メイン背景、サイドバー、エディタ、アクセントカラーなど 7 項目の色を自由に調整
- テーマのリアルタイムプレビューとワンクリック切り替え

### アカウントシステム
- タイトルバーにアカウントアバターボタンを追加（ピンの左側、区切り線付き）
- 初回起動時にアカウントがない場合、自動的に登録タブを開く
- 簡易登録：アカウント名（必須）と表示名のみ入力
- アバター未設定時、イニシャルアバターを自動生成（ランダム配色背景）
- アカウントデータはローカル保存（`User/account.json`）、パッケージには含まれない
- カスタムアバターのアップロード/削除に対応（2MB 以内）
- アカウント名バリデーション：英語、数字、アンダースコア、ハイフンのみ（2-20 文字）
- 表示名は任意の文字に対応（最大 30 文字）
- 設定ページのアカウント欄でインライン編集に対応（「編集」をクリック、Enter/フォーカス外しで確定、Esc でキャンセル）
- アカウント削除は二重確認で誤操作を防止
- プロジェクト作成ページの「所有者」情報が現在のアカウント名とアバターを動的表示

### 純 Markdown モード
- プロジェクト作成時に純 Markdown モードを選択可能（作成後は変更不可）
- 折りたたみ可能なリアルタイムプレビューパネル
- Markdown 専用ツールバー
- 既存の保存・ステータスバー機能と互換

### ファイルジャンプ機能
- プロジェクト内ファイル+見出しナビゲーションに対応（テキストアンカー使用、安定可靠）
- 外部 URL ジャンプに対応
- リッチテキストと Markdown ツールバーの両方にジャンプボタンを提供

### デバッグモード
- `Ctrl+Shift+D` でデバッグパネルを開く
- クイック操作：テストプロジェクトの作成/削除、最近のプロジェクト一覧、状態エクスポート、キャッシュクリア
- リアルタイム状態表示
- 操作ログ記録
- DevTools へのクイックアクセス

## インターフェース改善

- テキストの読みやすさを向上：WE Exclusive テーマの配色を調整、より深い文字色、より高いコントラスト
- ピンアイコンをより明確な押しピン形状に再デザイン
- 設定ページのアカウント欄に垂直中央揃えレイアウトを採用（アバターが上、名前/ニックネームが下）
- 設定下部バーを統一：アカウント削除は左、適用ボタンは右
- アカウント登録ページを中央レイアウトに、新規プロジェクトページと統一感を持たせた
- グローバルスクロールバーを美化：角丸デザイン、細窄スタイル、ホバー時ハイライト、テーマ色に自适应

## プロジェクト作成の改善

- 「プロジェクトを初期化」オプションを削除、テンプレート/説明欄との競合を回避
- プロジェクト説明を入力すると README.txt を自動作成
- テンプレート選択時に README の存在を保証

## バグ修正

- 設定ページのアカウント削除ボタンが初期表示されていた問題を修正
- アカウント削除ボタンが誤って編集ダイアログを開く問題を修正
- アカウント情報変更後、タイトルバーとプロジェクト作成ページにリアルタイム同期されない問題を修正
