# World Editor v0.7.0

## 新機能
- **ノードグラフエディター**: 純粋な SVG/CSS ノードグラフエンジン（NGEngine）を搭載。5 種類のノード（キャラクター·角丸矩形赤 / シーン·矩形青 / イベント·楕円緑 / 設定·菱形紫 / チャプター·矩形橙）、4 方向ベジェ接続ポート、4 種類の接続スタイル（関係·実線青 / 時系列·実線緑 / 因果·破線橙 / 所属·矢印なし紫）をサポート。ドラッグでノード作成、Shift+ドラッグで範囲選択、ホイールズーム（20%-400%）、リアルタイム座標表示。プロパティパネルでノード/エッジ属性編集、レイヤー管理、タイプ切替。旧 LogicFlow/G6 形式データの自動移行。
- **グローバル/ローカル Undo/Redo システム**: Photoshop スタイルの履歴パネル。グローバル（ファイル横断）とローカル（単一ファイル）の 2 つの Undo モードをサポート、最大 50 ステップの操作履歴。パネルはドラッグ移動可能で、ウィンドウリサイズ時にビューポート内に自動収束。
- **UI レイアウト再構築**: 3 状態モード（OA スタートページ / ディレクトリ専用 / 完全 TA）を導入。設定ページとプロジェクトページで統一された .only-left 切替機構を共有。サイドバーの背景が OA/TA モード間でスムーズに遷移。設定ナビゲーションに Lucide アイコンを追加（一般/タグ/アカウント/外観/エディター/ショートカット/概要）。
- **設定ユーザー情報カード**: 設定ナビゲーション上部にユーザーアバター、表示名、自己紹介/署名エリアを追加。アカウントタブ内で署名の編集をサポート、OA/TA モード切替時にスムーズな折りたたみアニメーション。
- **「デフォルトで最初の項目を開く」トグル**: 設定 > 一般に追加。有効にすると設定/エディターが常に TA モード（デュアルペイン）で開く。デフォルト: オフ。
- **i18n 補完**: ui.bio、ui.bio_placeholder、ui.bio_empty、ui.history、ui.default_open_first の翻訳を追加。中/英/日/露の 4 言語に対応。

## 改善
- 設定ページにドラッグ可能な分割バーを追加。プロジェクトファイルツリーと同じ .area-resizer ロジックを使用。
- エディターツールバー（リッチテキスト）とノードグラフツールバーの最小高さ（44px）とボタンサイズ（32×32）を統一。
- ノードグラフプロパティパネルの入力ボックス、ドロップダウン、カラーピッカーが --bg-input CSS 変数でテーマ適応。
- 保存デバウンスを強化。ノードグラフの内容切替時はデュアルキーキャッシュ（フルパス + ファイル名）でデータ損失を防止。

## 修正
- 設定ナビゲーションのハイライトが角丸からはみ出る問題を修正（.settings-nav-items に overflow: hidden を追加）。
- ノードグラフのエッジカラー検証（正規表現 ^#(3/6桁 hex)$）と単一エッジレンダリングエラーの耐障害性を修正。
- ノードグラフのエッジヒット検出を 28px 幅の透明ヒットパスで行い、小さなエッジでも選択可能に。
- ノードグラフのズーム後のテキストサイズ自動調整を修正（SVG_fontSize = clamp(MIN, base×zoom, MAX)/zoom）。
- ノードグラフのカメラ移動範囲制限を修正。ズーム係数と動的パディングを考慮。
- 履歴パネルがドラッグやウィンドウリサイズ時にビューポート外に出る問題を修正。
- Quill エディターの残留表示問題を修正（タブ閉じ時に #quill-storage コンテナに移動）。
