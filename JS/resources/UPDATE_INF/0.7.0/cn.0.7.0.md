# World Editor v0.7.0

## 新增功能
- **节点图编辑器**：全新的纯 SVG/CSS 节点图引擎（NGEngine），支持 5 种节点类型（角色·圆角矩形红 / 场景·矩形蓝 / 事件·椭圆绿 / 设定·菱形紫 / 章节·矩形橙）、4 方向贝塞尔连线端口、4 种连线样式（关系·实线蓝 / 时序·实线绿 / 因果·虚线橙 / 所属·无箭头紫）；支持拖拽创建节点、Shift+拖拽框选、鼠标滚轮缩放（20%-400%）、实时坐标显示；属性面板支持节点/连线的属性编辑、分层管理、类型切换；自动迁移 LogicFlow/G6 旧格式数据。
- **全局/局部撤销系统**：仿 Photoshop 风格的历史记录面板，支持全局（跨文件）和局部（单文件）两种撤销模式，最多保留 50 步操作历史；面板支持拖拽移动，窗口缩放时自动限制在可视区域内。
- **界面布局重构**：引入三态模式系统（OA 启程页 / 目录独占 / 完整 TA），设置页和项目页共享统一的 .only-left 切换机制；侧边栏背景色在 OA/TA 模式间平滑过渡；设置导航栏新增 Lucide 图标（通用/标签/账户/外观/编辑器/快捷键/关于）。
- **设置页用户信息卡片**：设置导航栏上方新增用户头像、显示名称、简介/签名区域；支持在账户选项卡内编辑签名，切换 OA/TA 模式时卡片带平滑折叠动画。
- **设置-通用新增"默认打开第一项"开关**：开启后设置/编辑器始终以 TA 模式（双区域）打开，默认关闭。
- **国际化补全**：补充 ui.bio、ui.bio_placeholder、ui.bio_empty、ui.history、ui.default_open_first 等缺失翻译，覆盖中/英/日/俄四语言。

## 优化
- 设置页新增可拖拽分割条，与项目文件树使用相同的 .area-resizer 逻辑。
- 编辑器工具条（富文本栏）和节点图工具条统一最小高度（44px）和按钮尺寸（32×32）。
- 节点图属性面板输入框、下拉框、颜色选择器等统一使用 --bg-input CSS 变量适配主题。
- 保存防抖逻辑增强，节点图内容切换时使用双键缓存（全路径+文件名）防止内容丢失。

## 修复
- 修复设置导航栏高亮溢出圆角的问题（.settings-nav-items 添加 overflow: hidden）。
- 修复节点图连线的颜色校验（正则 ^#(3/6 位 hex)$）和单条连线渲染异常容错。
- 修复节点图边缘选中检测使用 28px 宽透明 hit 路径，确保小尺寸连线可点击。
- 修复节点图缩放后文字大小自适应（SVG_fontSize = clamp(MIN, base×zoom, MAX)/zoom）。
- 修复节点图相机移动范围限制，考虑缩放因子和动态 padding。
- 修复历史记录面板拖拽和窗口缩放时超出可视区域的问题。
- 修复 Quill 编辑器残留显示问题（关闭标签页时移至 #quill-storage 容器）。
