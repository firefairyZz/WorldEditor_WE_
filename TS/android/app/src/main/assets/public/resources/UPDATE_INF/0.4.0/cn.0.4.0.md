# World Editor v0.4.0

## 新增功能

### 多主题系统
- 内置 13 种预设主题
  - 亮色：WE Exclusive、默认亮色、GitHub Light、Solarized Light、Nord Light
  - 暗色：默认暗色、Dracula、Monokai、Solarized Dark、Nord、GitHub Dark、One Dark
- 自定义主题：自由调配主背景、侧边栏、编辑器、强调色等 7 项颜色
- 主题实时预览与一键切换

### 账户系统
- 标题栏新增账户头像按钮（位于大头针左侧，带分隔线）
- 首次启动无账户时自动弹出注册标签页
- 注册流程极简：仅需填写账户名称（必填）和显示名称
- 无头像时自动生成首字母头像（随机配色背景）
- 账户数据本地存储（`User/account.json`），不随打包发布
- 支持上传/移除自定义头像（限 2MB 以内）
- 账户名称验证：仅支持英文、数字、下划线、连字符（2-20 字符）
- 显示名称支持任意字符（最多 30 字符）
- 设置页账户区支持行内编辑（点击"修改"，回车/失焦确认，Esc 取消）
- 删除账户双重确认，防止误操作
- 项目创建页"所有者"信息动态显示当前账户名称和头像

### 纯 Markdown 模式
- 创建项目时可选纯 Markdown 模式（创建后不可修改）
- 可折叠实时预览面板
- Markdown 专属工具栏
- 兼容现有保存和状态栏功能

### 文件跳转功能
- 支持项目内文件+标题导航（使用文本锚点，稳定可靠）
- 支持外部 URL 跳转
- 富文本和 Markdown 工具栏均提供跳转按钮

### 调试模式
- `Ctrl+Shift+D` 打开调试面板
- 快捷操作：创建/删除测试项目、列出最近项目、导出状态、清除缓存
- 实时状态显示
- 操作日志记录
- DevTools 快速访问

## 界面优化

- 文本可读性提升：WE Exclusive 主题配色调整，更深文字色、更高对比度
- 大头针图标重新设计为更清晰的图钉造型
- 设置页账户区采用垂直居中布局（头像居上，名称/昵称在下）
- 设置底栏统一操作：删除账户居左，应用按钮居右
- 账户注册页居中布局，与新建项目页风格统一
- 全局滚动条美化：圆角设计、细窄样式、悬停高亮，与主题色自适应

## 项目创建改进

- 移除"初始化项目"选项，避免与模板/描述字段冲突
- 填写项目描述自动创建 README.txt
- 选择模板确保 README 存在

## Bug 修复

- 修复设置页删除账户按钮初始可见的问题
- 修复删除账户按钮错误打开编辑对话框的问题
- 修复账户信息变更后标题栏和项目创建页未实时同步的问题
