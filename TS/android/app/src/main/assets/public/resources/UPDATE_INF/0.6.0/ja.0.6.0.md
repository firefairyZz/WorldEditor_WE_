# World Editor v0.6.0

## 新機能
- **プロジェクト固定**: スタートページに「固定プロジェクト」エリアを追加。よく使うプロジェクトを先頭に固定表示（ピンアイコンと更新日時を表示）。エディタサイドバーのプロジェクト名横に固定ボタンを追加し、素早く固定/解除可能。新規プロジェクト作成時に「スタートページに固定」チェックボックスを追加。
- **初回起動チュートリアル**: 初回起動時に「使い方チュートリアル」を自動的にスタートページに固定。パッケージ版ではアプリリソースからユーザーディレクトリにチュートリアルを自動コピー。
- **リッチテキスト色・整列**: Quillツールバーに文字色、背景色、テキスト整列（左/中央/右/両端）機能を追加。
- **ファイル複数選択・一括操作**: ファイルツリーで Ctrl+クリック複数選択、Shift+クリック範囲選択、Ctrl+A 全選択をサポート。選択後に下部ツールバーが表示され、一括タグ追加、一括タグ削除、一括削除が可能。
- **フォルダタグ**: フォルダのタグ追加・管理をサポート。右クリックメニューに「タグ管理」を追加、フォルダ名横にタグを表示。
- **一括タグ削除**: タグ選択パネルで各タグの選択項目内ヒット数を表示、チェックしてワンクリックで削除。

## ショートカット
- **Ctrl+A**（全ファイル選択）と **Ctrl+T**（一括タグ追加）ショートカットを追加、設定でカスタマイズ可能。

## 改善
- `recent.json` 構造を `{ pinned, recent }` にアップグレード、旧配列形式との後方互換性あり。
- 固定プロジェクトが「最近開いた」リストで上書きされないよう修正。固定状態がスタートページとエディタ間で同期。
