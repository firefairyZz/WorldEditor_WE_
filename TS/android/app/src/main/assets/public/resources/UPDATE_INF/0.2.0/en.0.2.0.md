# World Editor v0.2.0

## New Features

- **Tag System**: Add colored tags to files, supports text and emojis
- **Image Thumbnails**: Set thumbnails for files, images stored in project directory
- **Inline Features**: Table of contents, word count, Markdown export
- **Search**: Search by filename, tag, and content
  - Wildcard support (* and ?)
  - Fuzzy search
  - Multi-type filtering
  - Result sorting
- **File Tree Optimization**: Adjustable sidebar width, improved expand/collapse triangles

## UI Improvements

- Enhanced editor interface
- Collapsible search bar
- Filter buttons changed to toggle style
- Improved responsive layout

## Bug Fixes

- Fixed metadata loading race condition
- Fixed TOC position calculation error
- Fixed Markdown export link format
- Fixed CSS compatibility issues
