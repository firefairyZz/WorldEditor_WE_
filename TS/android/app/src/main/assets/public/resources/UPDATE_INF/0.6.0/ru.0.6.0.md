# World Editor v0.6.0

## Новые функции
- **Закрепление проектов**: На стартовой странице добавлена секция «Закреплённые проекты». Часто используемые проекты можно закрепить наверху (с иконкой булавки и временем изменения). В боковой панели редактора рядом с именем проекта добавлена кнопка закрепления. При создании нового проекта доступна опция «Закрепить на стартовой странице».
- **Туториал при первом запуске**: При первом запуске «Руководство» автоматически закрепляется на стартовой странице. В упакованной версии туториал копируется из ресурсов приложения в пользовательскую директорию.
- **Цвет и выравнивание текста**: В панель инструментов Quill добавлены выбор цвета текста, цвета фона и выравнивание (лево/центр/право/по ширине).
- **Множественный выбор и массовые операции**: Файловое дерево поддерживает Ctrl+Клик для множественного выбора, Shift+Клик для выбора диапазона и Ctrl+A для выбора всех. При выборе элементов внизу появляется панель с массовыми операциями: добавление тегов, удаление тегов и удаление файлов.
- **Теги для папок**: Папки теперь поддерживают теги. В контекстное меню папки добавлен пункт «Управление тегами», теги отображаются рядом с именем папки.
- **Массовое удаление тегов**: Панель выбора тегов показывает количество совпадений каждого тега в выбранных элементах; отметьте теги и удалите их одним нажатием.

## Горячие клавиши
- Добавлены **Ctrl+A** (Выбрать все файлы) и **Ctrl+T** (Массовое добавление тегов), настраиваемые в параметрах.

## Улучшения
- Структура `recent.json` обновлена до `{ pinned, recent }` с обратной совместимостью со старым форматом массива.
- Закреплённые проекты больше не перезаписываются списком «Недавние»; статус закрепления синхронизирован между стартовой страницей и редактором.
