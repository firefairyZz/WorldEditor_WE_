# World Editor v0.7.0

## Новые функции
- **Редактор графов узлов**: Новый движок графов узлов на чистом SVG/CSS (NGEngine) с 5 типами узлов (Персонаж·скруглённый прямоугольник красный / Сцена·прямоугольник синий / Событие·эллипс зелёный / Настройка·ромб фиолетовый / Глава·прямоугольник оранжевый), 4-направленными портами Безье, 4 стилями соединений (Отношение·сплошная синяя / Хронология·сплошная зелёная / Причина-следствие·пунктирная оранжевая / Принадлежность·без стрелки фиолетовая). Поддерживает создание узлов перетаскиванием, выделение рамкой Shift+перетаскивание, масштабирование колёсиком (20%-400%), отображение координат в реальном времени. Панель свойств для редактирования атрибутов узлов/рёбер, управления слоями, переключения типов. Автоматическая миграция данных из старого формата LogicFlow/G6.
- **Глобальная/локальная система отмены**: Панель истории в стиле Photoshop с поддержкой глобального (межфайлового) и локального (однофайлового) режимов отмены, до 50 шагов истории. Панель можно перетаскивать, при изменении размера окна она автоматически фиксируется в пределах видимой области.
- **Рефакторинг макета интерфейса**: Внедрена трёхрежимная система (OA стартовая страница / только директория / полный TA), с единым механизмом переключения .only-left для страниц настроек и проектов. Фон боковой панели плавно переходит между режимами OA и TA. Навигация настроек теперь использует иконки Lucide (Общие/Теги/Аккаунт/Внешний вид/Редактор/Горячие клавиши/О программе).
- **Карточка пользователя в настройках**: Добавлены аватар, отображаемое имя и область биографии/подписи над навигацией настроек. Поддерживается редактирование подписи на вкладке «Аккаунт», плавная анимация свёртывания при переключении между OA/TA режимами.
- **Переключатель «Открывать первый пункт по умолчанию»**: Добавлен в Настройки > Общие. При включении настройки/редактор всегда открываются в режиме TA (двухпанельный). По умолчанию: выкл.
- **Завершение i18n**: Добавлены недостающие переводы для ui.bio, ui.bio_placeholder, ui.bio_empty, ui.history, ui.default_open_first, охватывающие китайский, английский, японский и русский языки.

## Улучшения
- Страница настроек теперь имеет перетаскиваемую разделительную панель, использующую ту же логику .area-resizer, что и файловое дерево проекта.
- Панель инструментов редактора (rich text) и панель инструментов графа узлов объединены с единой минимальной высотой (44px) и размером кнопок (32×32).
- Поля ввода, выпадающие списки и палитры цветов на панели свойств графа узлов используют CSS-переменную --bg-input для единой адаптации темы.
- Улучшена логика анти-флуда сохранения; при переключении содержимого графа узлов используется двойное кэширование (полный путь + имя файла) для предотвращения потери данных.

## Исправления
- Исправлено переполнение подсветки навигации настроек за пределами скруглённых углов (добавлен overflow: hidden для .settings-nav-items).

- Исправлено обнаружение попадания в ребро графа узлов с использованием 28px прозрачного пути для удобного выбора маленьких рёбер.
- Исправлено автоматическое масштабирование текста после зума графа узлов (SVG_fontSize = clamp(MIN, base×zoom, MAX)/zoom).
- Исправлены границы движения камеры графа узлов с учётом коэффициента зума и динамического отступа.
- Исправлена проблема выхода панели истории за пределы окна при перетаскивании и изменении размера окна.
- Исправлена проблема остаточного отображения редактора Quill (перемещение в контейнер #quill-storage при закрытии вкладок).
