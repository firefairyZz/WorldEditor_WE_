# World Editor v0.4.2

## 新機能と改善
- **国際化対応の強化**：UI内の未翻訳キーを修正し、更新履歴のディレクトリ構造を整理して双言語対応（`vx.y.z/cn.md`と`vx.y.z/en.md`）を統一。
- **タグシステムのリファクタリング**：タグモジュールの内部リンクロジックを全面改修。**よく使うタグ**の自動追跡機能を追加し、設定ページに**固定タグ**管理パネルを新設して素早く呼び出せるように。
- **エディタUXの向上**：ドキュメント目次の読み込みロジックを最適化。リッチテキストモードでタグ追加時にテキストが誤って削除されるバグを修正。

## バグ修正
- タグポップアップの位置と背景オーバーレイの追従問題を修正。
- 下部ボタンバーのレイアウトを改善し、アクションボタンがポップアップ底部に固定され、スクロール可能なコンテンツと重ならないように。
- タグパネルと設定ページのカード視覚スタイルを統一し、一貫性のある体験を実現。
