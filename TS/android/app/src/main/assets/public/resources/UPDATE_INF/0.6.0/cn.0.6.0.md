# World Editor v0.6.0

## 新增功能
- **项目固定**：启程页新增"固定的项目"区域，支持将常用项目置顶显示（带大头针图标和修改时间）；编辑器侧边栏项目名旁新增固定按钮，点击可快速固定/取消固定；新建项目时可选"将此项目固定到启程页"。
- **首次运行教程**：首次打开软件时自动将"使用教程"固定到启程页，打包环境下自动从程序资源复制教程到用户目录。
- **富文本上色与对齐**：Quill 工具栏新增文字颜色、背景颜色和文本对齐（左/居中/右/两端）功能。
- **文件多选与批量操作**：文件树支持 Ctrl+点击多选、Shift+点击范围选择、Ctrl+A 全选；多选后底部弹出工具栏，支持批量加标签、批量删标签和批量删除。
- **文件夹标签**：文件夹支持添加和管理标签，右键菜单新增"管理标签"选项，文件夹名旁显示标签。
- **批量删标签**：弹出标签选择面板，显示每个标签在选中项中的命中数，勾选后一键删除。

## 快捷键
- 新增 **Ctrl+A**（全选文件）和 **Ctrl+T**（批量加标签）快捷键，可在设置中自定义。

## 优化
- `recent.json` 结构升级为 `{ pinned, recent }`，向后兼容旧格式。
- 固定项目不会被"最近打开"列表覆盖，固定状态在启程页和编辑器间保持同步。
