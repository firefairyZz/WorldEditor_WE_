# World Editor v0.5.0

## 新增与优化
- **多格式导出**：原"导出 Markdown"按钮升级为下拉菜单，支持 **Markdown / HTML / PDF / ZIP** 四种格式。PDF 通过隐藏窗口 `printToPDF` 生成（A4、无边距、保留背景色）；ZIP 将整个项目打包保存。
- **背景材质系统增强**：材质类型新增**标签式 (Tabbed)**；新增**内容区 / 遮罩 / 标题栏**三层透明度滑块（默认 78% / 30% / 100%），设置页实时预览，材质为"无"时滑块自动灰化。
- **新增语言包**：补齐**日语**与**俄语**完整翻译，设置页语言下拉新增对应选项。
- **标签自定义颜色**：标签颜色选择器在预设色板旁新增取色器，支持任意自定义颜色，两者联动同步。
- **保存防抖**：保存期间再次请求会自动排队补存，并在通知栏持续显示"正在保存..."，完成后切换为"已保存"。
- **窗口启动优化**：主窗口改为 `ready-to-show` 后再显示，避免启动白闪。
- **置顶按钮图标**：改用 `pin.svg` 资源，通过 `rotate(45deg)` 区分激活态。
- **布局与样式**：页面重构为 title-bar / tab-bar / #main 三段式；`html`/`body` 始终透明，不透明色交由各子区块承担；标签选择器对话框加入毛玻璃遮罩与上滑动画。
- **国际化刷新**：补全标签区、账户区、外观区（材质组 + 配色组）的多语言刷新。

## 修复与调整
- 修复富文本加载内容时换行与格式解析错乱的问题（HTML 走 `dangerouslyPasteHTML`，纯文本走 `setText`）。
- 修复 Quill 标题下拉默认值导致的正文格式异常（默认值由 `""` 改为 `"false"`）。
- 修复切换配色预设后旧半透明颜色污染新主题的问题（切换时清除主题色缓存并重新应用材质）。
- 修复窗口不透明背景色覆盖材质效果的问题（窗口始终透明，圆角由 CSS `clip-path` 处理）。
- 规范化文件名显示：跳转对话框、标签标题、导出文件名统一去扩展名、去路径。
