# World Editor v0.8.0

## 新增功能

### 卡片系统（全新）
- **图片卡片（ImageCardBlot）**：在富文本编辑器中插入图片卡片，支持拖拽调整大小、注释编辑、选中/多选/批量删除；旧内容中的 `<img>` 标签自动升级为 ImageCard。
- **网址卡片（UrlCardBlot）**：内联级卡片，显示链接图标和 URL，双击直接打开外部链接。
- **文件链接卡片（FileLinkCardBlot）**：展示文件图标、文件名、描述信息，双击跳转到项目内目标文件。
- **节点图链接卡片（NodeGraphCardBlot）**：展示节点图实时缩略图（SVG 渲染），双击打开嵌入节点图编辑器；支持指定目标节点居中显示。
- 卡片支持 Shift/Ctrl+点击多选、Delete/Backspace 批量删除、ESC 取消选中。

### 节点图导出 HTML
- 节点图支持导出为独立 HTML 展示页，包含完整 SVG 渲染、贝塞尔连线、鼠标拖拽平移、滚轮缩放（20%-400%）、节点悬停提示（名称/描述）。
- 导出文件可脱离编辑器在浏览器中独立使用。

### 共享 SVG 渲染引擎
- 抽象 `generateNodeGraphSVG()` 共享函数，统一节点图导出 HTML 与缩略图生成使用同一渲染管线，确保视觉一致性。
- 支持自定义视口、背景色、网格、节点透明度、连线粗细、non-scaling stroke 等选项。

### 文件简介系统
- 文件树右键菜单新增"管理简介"入口，可为文件添加多行文本描述。
- 文件树中文件名下方显示简介文本。
- 简介数据通过 `tagModule.getDesc()` / `setDesc()` 存储于元数据文件。

### 智能括号
- 编辑器自动补全括号（`()`, `[]`, `{}`, `""`, `''`），支持退格删除配对括号。

## 架构重构
- **CSS 架构重构**：将 `style.css` 拆分为 5 个模块化 CSS 文件（`base.css` / `layout.css` / `components.css` / `node-graph.css` / `quill.css`），提升可维护性和加载性能。
- **编辑器模块拆分**：将 `editor.js` 拆分为 `editor/` 目录下的独立模块（`core.js` / `markdown.js` / `export.js` / `links.js` / `mode-switch.js` / `blots.js` / `globals.js` / `embed.js` / `undo.js` / `toolbar.js` / `smart-brackets.js`），降低文件耦合度。

## 优化
- **设置页导航 i18n 刷新优化**：刷新导航文本时保留 Lucide 图标 SVG，避免图标丢失。
- **透明模式实色变量**：新增 `--bg-sidebar-solid`、`--bg-main-solid`、`--border-solid` CSS 变量，确保透明模式下开关、输入框等组件使用实色背景。
- **节点图端口方向传递**：`getPortPos()` 返回端口方向（side），确保贝塞尔曲线控制点计算正确。
- **节点图导出 HTML 拖拽优化**：放宽拖拽事件限制，允许在 SVG 任意区域拖拽，排除工具栏按钮误触。
- **缩略图 AABB 计算修正**：使用中心坐标（`n.x ± halfWidth`）计算节点边界，与 NGEngine 引擎坐标系统一致。
- **标签切换/关闭时取消选中卡片**：`_deselectImageCard()` 确保切换标签时卡片选中状态正确清理。
- **对话框工具函数**：新增 `showTextInputDialog()` 支持翻译的文本输入对话框。

## 修复
- **修复所有弹窗（警告/提示/确认）美化丢失**：`components.css` 文件第 1220 行 CSS 选择器截断导致后续所有样式失效；CSP 中 `default-src 'self'` 在 `file://` 协议下阻止 CSS 加载；补充缺失的弹窗按钮、确认框、模式切换框等样式定义。
- **修复节点图导出 HTML 连线非贝塞尔曲线**：端口方向未传递导致控制点计算错误。
- **修复节点图导出 HTML 无法拖拽视角**：拖拽事件限制过于严格。
- **修复节点图缩略图与导出 HTML 渲染不一致**：两者使用独立 SVG 生成逻辑，现统一为共享渲染函数。
- **修复节点坐标对不准**：缩略图 AABB 计算错误地将节点中心坐标当作左上角坐标。
- 多项文件树、标签系统、设置页的细节修复。
