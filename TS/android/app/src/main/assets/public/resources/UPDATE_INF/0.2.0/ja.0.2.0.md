# World Editor v0.2.0

## 新機能

- **タグシステム**：ファイルにカラータグを追加、テキストと絵文字をサポート
- **画像サムネイル**：ファイルにサムネイルを設定、画像はプロジェクトディレクトリ内に保存
- **インライン機能**：目次生成、文字数カウント、Markdown 書き出し
- **検索機能**：ファイル名、タグ、内容で検索
  - ワイルドカード対応（* と ?）
  - ファジー検索
  - 多様なタイプの絞り込み
  - 結果の並べ替え
- **ファイルツリー最適化**：サイドバー幅調整可能、展開/折りたたみ三角形を改善

## インターフェース改善

- エディタインターフェースの美化
- 検索バーの折りたたみ対応
- フィルターボタンをトグルスタイルに変更
- レスポンシブレイアウトの改善

## バグ修正

- メタデータ読み込みの競合状態を修正
- 目次位置計算エラーを修正
- Markdown 書き出しリンク形式を修正
- CSS 互換性の問題を修正
